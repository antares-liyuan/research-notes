# 个人 AI 自动交易研究方案（以股票为主）

> 2026-11-24 · 历元研究笔记 · 约 8 分钟阅读
> 适用对象：想研究 AI 辅助交易的个人投资者
> 性质：研究方案，**不构成投资建议**。所有交易风险由使用者自行承担。

## 一句话总结

**让 AI 负责研究、筛选和复盘；买不买、买多少由写死的规则决定；风控是硬代码，AI 改不了。**

每一笔交易都要能查到，先证明有效再投钱。一夜几十倍的事不会发生，这套系统追求的是**有纪律、可复盘、长期可能小幅跑赢指数**。

---

## 背景：为什么要这样设计

社交媒体上流行一类爆款帖：「用 Grok Bot 开 5～6 个子代理，睡前投 50 美元，第二天醒来变成 2 万多美元」，附一段仪表盘视频。拆解后发现它们有共同破绽：

- 画面上有小字 **"trade-level detail illustrative"**（交易明细仅作示意）；
- 视频 20 秒走完 23:00 到 07:00，是动画而不是实时录屏；
- 不同作者、不同本金，交易笔数和胜负数却一模一样（例如都是 64 笔、43 赚、21 亏），明显是同一个模板；
- 没有钱包地址、交易哈希，没法核对；
- 真正能落地的只有交易平台的邀请返佣链接，或者让你「绑定钱包」。

这些帖子的问题在于：**把下单和仓位全交给「代理」，又拿不出可以核对的记录**。本方案的设计反过来做。

---

## 一、四条基本原则

1. **只认可核对的结果**：每一笔要有券商成交单号和完整日志。视频、仪表盘、截图都不算数。
2. **模拟盘在前**：回测通过、模拟盘也通过，才能投真钱。
3. **资金分层**：实盘先用能接受全亏的钱，交易账户和主账户分开。
4. **AI 不碰钥匙**：交易接口密钥只给执行程序，不给大模型；不用来路不明的「机器人」或代运营。

---

## 二、先选市场（最关键的一步）

| 市场 | 接口 | 优点 | 限制 |
| --- | --- | --- | --- |
| **美股（入门首选）** | Alpaca（免费模拟盘和下单 API）、盈透 IBKR | 门槛低，接口开放，适合个人研究 | 日内交易规则（PDT）近年在调整，以券商当时规定为准 |
| **A 股** | 券商提供的 QMT、PTrade | 熟悉的市场，数据源丰富 | 多数券商有资产门槛；2025 年起程序化交易需向券商报备；T+1、涨跌停、卖出印花税，短线成本高 |
| **加密货币** | 交易所 API | 接口最开放，7×24 小时 | 骗局和噪音最多，不建议拿来入门 |

**建议**：先用美股 Alpaca 模拟盘把整套系统跑通；要做 A 股，同一套策略再接 QMT。

---

## 三、系统架构

借用「多个代理分工」的思路，但每一层的职责和权限都写清楚：

```text
数据层 → 研究层（AI）→ 策略层（规则）→ 风控层（硬代码）→ 执行层 → 日志与复盘
```

| 层 | 负责什么 | 谁来做 |
| --- | --- | --- |
| 1. 数据层 | 行情、财务、新闻公告。美股：yfinance、Polygon、Alpaca 自带数据；A 股：Tushare、AkShare，并用交易所公告交叉验证 | 程序 |
| 2. 研究层 | 读财报、公告、新闻，打分并给出理由（如「业绩超预期」「有减持风险」），输出固定格式数据，**不直接下单** | **AI 主要发挥作用的地方** |
| 3. 策略层 | 例如「动量排名前 10 且 AI 情绪分 ≥ 7 才买入」，每周或每天调仓一次 | 规则，不是 AI |
| 4. 风控层 | 单只股票 ≤ 总资金 10%；单日亏损超 2% 当天停止交易；总回撤超 10% 全部暂停、等人工确认；单笔下单有金额上限 | 硬代码，**AI 无权修改** |
| 5. 执行层 | 只调用券商 API 下单；下单前先过风控检查；用限价单 | 程序 |
| 6. 日志与复盘 | 每笔记录信号、理由、成交价、滑点；每天收盘后 AI 写复盘，人早上看 | 程序 + AI + 人 |

**入门做中低频，不做日内**。个人拼速度拼不过机构，AI 的强项是读信息，不是抢毫秒。

---

## 四、分阶段推进，每一关都有过关标准

| 阶段 | 时长 | 内容 | 过关标准 |
| --- | --- | --- | --- |
| 第 0 阶段：环境 | 约 2 周 | Python 环境、数据入库、开通券商模拟账户 | 数据能稳定每日更新 |
| 第 1 阶段：回测 | 4～6 周 | 至少 3～5 年历史数据，计入手续费、滑点、印花税 | 扣完成本跑赢基准指数（沪深 300 或标普 500）；最大回撤可接受；换一段时间测试，结论不反转 |
| 第 2 阶段：模拟盘 | 至少 2～3 个月 | 股票交易次数比加密少，一两周样本不够 | 模拟盘表现与回测基本一致；没有出现下错单、重复下单等事故 |
| 第 3 阶段：小资金实盘 | 3 个月以上 | 只投能接受全亏的钱 | 真实滑点和执行成本在预期内 |
| 第 4 阶段：逐步增加资金 | 持续 | 每次增加投入资金前复核最近一段实盘数据 | 实盘指标稳定 |

## 五、最容易踩的坑

- **未来函数**：回测时用了当时还拿不到的数据，比如财报其实是收盘后才发布的。
- **过拟合**：参数调到回测曲线很完美，一上实盘就失效。
- **幸存者偏差**：只用现在还在交易的股票回测，漏掉已经退市的。
- **低估成本**：A 股短线一来一回，手续费加印花税就不少。
- **让大模型直接预测涨跌**：这件事它不比随机猜好多少。它擅长的是把大量文字信息结构化。

## 六、大概的成本

- **美股路线**：数据和券商 API 可免费起步；大模型 API 每月几十美元以内（只做日频研究）；云服务器可选，每月约 10～20 美元。
- **A 股路线**：QMT 门槛视券商而定；Tushare 高级接口按积分付费。

## 附：识别「AI 交易暴富」帖子的方法

1. 找画面里的小字：illustrative、simulated、paper、demo 等字样。
2. 看时间：几十秒视频走完一整夜，就是动画或回放。
3. 要证据：问作者要钱包地址或券商对账单。链上交易可以在 Solscan、Tronscan 等浏览器公开核对；给不出的，一律当营销看。
4. 看链接：帖子里只有邀请返佣链接、付费群、「绑定钱包」入口的，目的就是这些链接。
5. **永远不要把私钥、助记词或交易授权交给任何机器人或网站。**
